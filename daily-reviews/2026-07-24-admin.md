## What was found / achieved
Overall a mature service: RBAC helpers, audit logging, rate limiting, bcrypt, non-root Docker image, healthcheck. Issues found:

1. **Missing authz on POST /roles** (`main.py` ~line 430, `create_role`): only rate-limited — no `_require_tenant_admin`/`_require_platform_admin` call. Any authenticated tenant user can create roles in their tenant. Contrast with `list_roles`/`update_role_permissions`, which do gate.
2. **Missing authz on POST /users** (~line 745, `create_user`): same pattern — no admin check before creating users (and optionally assigning them a role). Combined with #1 this could allow privilege escalation by a non-admin user.
3. **DEFAULT_USER_PASSWORD_HASH fallback** (~line 752): if a user is created without a password, the hash comes from a shared env var — every such user would share one password. Fallback to `secrets.token_hex(16)` is not a bcrypt hash (user unloginable — probably intended, but implicit).
4. **INTERNAL_SERVICE_KEY** (`/internal/users/by-email`, ~line 705): fails closed if unset (good), but the endpoint is in `public_paths` and gated only by a shared header secret — must be set in prod env; no rotation mechanism.
5. **Silent partial provisioning** (`create_tenant`, ~line 262): `provision_tenant(...)` failure is only `logger.warning` — tenant is created but may be half-provisioned with no surfaced error to the caller.
6. **In-process RateLimiter** with `--workers 2` in Dockerfile: limits are per-worker, so effective limits are 2x stated; not shared across replicas.
7. **No pagination** on `GET /tenants` and `GET /users` — unbounded result sets.
8. Minor: `_log_audit` swallows all exceptions (warning only) — acceptable, but audit trail can silently gap.

No TODO/FIXME markers, mock data, or hardcoded credentials found. Requirements delegate to `services/common/requirements.txt`.

## Critical decisions / flags
- **Decide:** should POST /roles and POST /users require tenant-admin? Almost certainly yes — this is the top fix, but confirming intended policy (e.g., self-signup flow?) is a human call.
- **Decide:** keep or remove `DEFAULT_USER_PASSWORD_HASH` shared-password fallback.
- **Ops:** ensure `INTERNAL_SERVICE_KEY` and `ADMIN_AUTO_PROVISION` are set in production env; decide whether provision failure should roll back tenant creation.
