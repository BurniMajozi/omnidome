### 2. Retention Journey Engine (`journey_engine` — port 8017)

Cancel-to-save lifecycle: when customer clicks cancel → rules evaluated → offer shown → outcome tracked → ML feedback.

**Backend:**
- `services/journey_engine/models.py` — 5 tables:
  - `retention_journeys` — journey definitions with trigger + rules + offer links
  - `journey_rules` — conditional targeting (attribute, operator, value)
  - `retention_offers` — discount/upgrade/pause/outreach offer templates
  - `cancel_events` — each cancel initiation with customer snapshot
  - `journey_outcomes` — accept/reject/expired + 90d/180d retention flags
- `services/journey_engine/rule_engine.py` — full if/then evaluator
  - 12 customer attributes (risk_score, segment, tenure_months, etc.)
  - Operators: eq, ne, gt, gte, lt, lte, between, in, not_in, contains
  - Rule groups: AND within group, OR across groups
  - Priority-based journey selection
- `services/journey_engine/journey_manager.py` — orchestrator
  - Customer snapshot builder
  - Offer eligibility checking (caps, plan requirements)
  - Cost computation per offer type
  - Outcome result calculator

**API Endpoints (20+):**
- `POST /cancel/trigger` — receives cancel → returns best journey + offer
- `POST /cancel/respond` → accept/reject → records outcome
- CRUD for journeys, rules, offers
- `GET /analytics/funnel` — triggered → shown → accepted/rejected
- `GET /analytics/outcomes` — outcome records for ML feedback
- `GET /analytics/roi` — ROI by journey
- `GET /attributes` — available attributes/operators for UI

**Offer Types Supported:**
1. `percentage_discount` — X% off for N months
2. `fixed_discount` — R X off for N months
3. `plan_downgrade` — move to cheaper plan
4. `service_pause` — pause for N months, keep tenure
5. `free_months` — N months free
6. `loyalty_reward` — bonus data/VAS
7. `personal_outreach` — flag for agent call

**Frontend:**
- `apps/web/components/modules/journey-builder/journey-builder-dashboard.tsx`
  - Journey CRUD with rule editor (inline condition rows)
  - Offer CRUD with type-specific parameter forms
  - Funnel visualization per journey (bar chart)
  - ROI table (discount cost vs revenue at risk)
- `apps/web/lib/journey-api.ts` — typed API client
- `apps/web/app/api/journey-engine/` — proxy routes to backend
- Retention module patched to use Journey Builder for journeys tab

## Architecture Decision

**Cancel flow integration point:** The portal's cancel button must call the Journey Engine's `POST /cancel/trigger` with a customer snapshot (risk_score, segment, tenure, spend, etc.). The engine returns the best matching offer, the portal displays it, and the customer's decision is recorded via `POST /cancel/respond`. All outcomes feed back to churn prediction via the `journey_outcomes` table with 90d/180d retention flags.
