## Key Architecture Decisions

1. **Supabase replaced by Communication Service** — module_data table for dashboard, chat module for internal comms
2. **Agent Orchestrator** — Ollama primary, OpenRouter fallback, 5 agents with role-based tool access
3. **Circuit Breaker** — prevents cascade failures in cross-service calls
4. **Tenant isolation** — all services use tenant_id-scoped queries via ContextVar
5. **POPIA compliance** — data stays on-prem via Ollama, PII scrubbing, audit trails
